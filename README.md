# LifeStyle Image Studio

A Next.js App Router starter for the LifeStyle AI image creation workspace.

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Stack
- Next.js 15 / React 19
- TypeScript
- Tailwind CSS 4
- Lucide icons

## Current scope
Premium responsive landing page and UI foundation. AI image generation, authentication, and persistence are **not yet implemented**.

## Deployment
Import this GitHub repository into Vercel using the Next.js framework preset. No environment variables are required for the starter.
